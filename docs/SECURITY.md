## 2. 인증·세션 (AUTH-001)

- 비밀번호 해시: **Argon2id** (Spring Security `Argon2PasswordEncoder`, 파라미터는 운영 서버에서 200~500ms 목표로 측정 후 확정). `DelegatingPasswordEncoder`로 향후 교체 가능하게.
- 로그인 시도 제한: 이메일 HMAC 기준 15분 5회 실패 → 15분 잠금, IP 기준 1시간 50회. 실패 응답은 원인 무관 동일 메시지.
- 세션: Spring Session JDBC, 유휴 30분 / 절대 7일(검토). 로그인 시 세션 ID 재발급. 로그아웃·비밀번호 변경·탈퇴 시 해당 사용자 세션 전부 삭제.
- 쿠키: `HttpOnly; Secure; SameSite=Lax; Path=/`.
- CSRF: `CookieCsrfTokenRepository` + `X-XSRF-TOKEN` 헤더.
- 이메일 인증코드·재설정 토큰: 해시만 저장, 단회용, 만료(10분/30분), 시도 제한.
- 계정 열거 방지: 가입·재설정 요청 응답을 이메일 존재 여부와 무관하게 동일하게.

## 3. 인가

- 모든 건강정보 조회는 리포지토리 메서드 수준에서 `userId`를 조건으로 강제(`findByIdAndUserId`). 서비스에서 "조회 후 비교" 방식 금지(실수 여지).
- 타인 리소스는 404.
- 관리자 기능은 MVP에 없음. 운영자 DB 직접 접근은 접근 기록이 남는 경로로만(운영 정책, 검토 필요).
- 테스트: 각 건강정보 엔드포인트마다 "사용자 B가 사용자 A의 리소스에 GET/PATCH/PUT/DELETE → 404" 통합 테스트 필수(완료 조건).

## 4. 파일 처리

- 저장 키: `documents/{random-uuid}` — 사용자 ID·파일명·검진일을 키에 넣지 않는다.
- 버킷: 퍼블릭 접근 차단, 서버 측 암호화(SSE), 버전 관리 off(삭제 보장) 또는 on + 수명 주기로 이전 버전 파기(결정 필요).
- 다운로드: 소유권 확인 후 60초 서명 URL, `Content-Disposition: attachment`, 응답 `Content-Type`은 저장된 검증 MIME.
- 미리보기 이미지: 서버가 렌더링한 PNG(원본 PDF를 브라우저 PDF 뷰어로 직접 열지 않음 → PDF 내 스크립트 위험 감소).
- 이미지 EXIF(위치정보 등) 제거 후 미리보기 생성. 원본은 그대로 보관(사용자 원본 보존) — 원본에서도 제거할지 결정 필요.
- ClamAV 서명 DB 자동 갱신(freshclam), 스캔 실패 시 거부.

## 5. 로깅·관측

- 금지: 요청/응답 본문, 측정값, 이메일 원문, 파일명, 토큰·쿠키·인증코드, 제공업체 응답 원문.
- 허용: 사용자 UUID, 리소스 UUID, 상태 코드, 오류 코드, 처리 시간, 파일 크기·MIME.
- Logback 마스킹 필터 + 정적 검사(테스트에서 로그 캡처 후 금지 패턴 검사).
- 오류 추적 도구 도입 시 `sendDefaultPii=false`, 본문 수집 off.
- 제품 분석 도구: MVP는 자체 이벤트(서버 측 퍼널 카운트)만. 서드파티 분석 SDK는 건강정보 화면에 넣지 않는다.

## 8. 법률·규제 검토 필요 항목 (출시 게이트)

> 아래는 확인해야 할 **질문**이며 결론이 아니다.

1. **민감정보 처리 근거**: 건강검진 결과가 개인정보보호법상 민감정보(건강)에 해당하는지, 별도 동의 방식(필수 동의 분리 고지 등)과 고지 항목.
2. **처리방침·동의서 문안**: 수집 항목, 목적, 보유 기간, 위탁, 국외 이전, 파기 방법.
3. **위탁·국외 이전**: 추출 제공업체·클라우드 리전에 따른 고지·동의 요건.
4. **안전성 확보조치**: 암호화 대상(고유식별정보·민감정보 범위), 접근 기록 보관 기간 등 기술적·관리적 보호조치 기준.
5. **의료기기 해당성**: 현재 기능(기록·추출·추이 표시·일반 설명)이 의료기기 또는 디지털의료제품에 해당하지 않는지, 특히 "참고범위 대비 표시"와 "변화량 표시"의 경계. 식약처 가이드라인(의료기기와 개인용 건강관리(웰니스) 제품 판단 기준 등) 확인.
6. **의료법 관련**: 설명 콘텐츠(INFO-001)가 의료행위·의료광고로 해석될 소지.
7. **14세 미만**: 가입 제한 방식.
8. **동의 이력 보관**: 탈퇴 후 동의 기록 보관 필요성과 기간.
9. **데이터 이동권·열람권**: 내보내기 형식이 요건을 충족하는지.

## 9. 의료 안전 가드레일 (구현 규칙)

- 앱이 생성하는 문장·라벨에 "정상/비정상/위험/개선/악화/의심/진단" 판정 표현을 쓰지 않는다(문서 원문 판정 인용은 출처 표기 시 허용).
- 수치 색상은 중립. 경고색은 추출 품질 문제에만.
- 추이·대시보드 입력은 확정값만(테스트로 보장).
- 생활 습관 정보(P1/P2)는 일반 정보로 한정, 개인 수치에 따른 맞춤 처방 문장 생성 금지.
- 모든 결과 화면에 상담 권고 고정 문구.
- 금지어 린트: 프론트 카피 파일에 금지 표현 정규식 검사(CI).
